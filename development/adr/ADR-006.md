# ADR-006  写端点契约表（W 映射）+ 契约测试

- 状态：已接受（2026-09-02 追认，Phase 4 落地）
- 关联：production-readiness-plan.md / lessons-learned.md

## 背景

前后端分离后，写操作 method/path/body 的"翻译"是高频漂移点（历史教训：hashStr/派车顺序/契约漂移均为翻译错）。

## 决策

前端 endpoints.js 维护 W 映射（写操作名 → {method, path(args), body(args)}，97 端点，按业务域分组）；check-contract.mjs 解析前端 W 映射 vs 后端 Controller 路由（@RequestMapping + @*Mapping），method+归一化 path 不一致即红（CI 拦截）。

## 备选方案

备选：① 手工维护 API 文档（漂移不可见，否）；② OpenAPI 代码生成（演示阶段工具链重，暂不）。

## 后果

收益：契约漂移自动化拦截（97/97 持续校验）；成本：新增端点需同步前后端 + 跑契约测试。
