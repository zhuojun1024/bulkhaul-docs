# ADR-007  验收栈 SCHEDULER_AUTO_ENABLED=false（确定性）

- 状态：已接受（2026-09-02 追认，Phase 4 落地）
- 关联：production-readiness-plan.md / lessons-learned.md

## 背景

在途进度/ETA/围栏由定时任务推进，自动开启时 E2E 场景 13（在途监控）的进度断言受 tick 时序影响 flaky。

## 决策

验收/验证栈显式 SCHEDULER_AUTO_ENABLED=false：进度由 node 侧手动驱动 POST /api/scheduler/tick（确定性）；前端 3s 轮询 tick 仅推进演示。生产栈为 true（C4 leader 单实例执行）。start_backend.sh/recreate_backend.sh 已固化 false。

## 备选方案

备选：① 全栈 true + 断言容忍漂移（flaky 不可接受，否）；② 测试专用 tick 接口（与手动驱动等价，已采用手动驱动）。

## 后果

收益：E2E 确定性（110 断言零 flaky）；成本：验收栈与生产栈配置差异需文档化（runbook 纪律）。
