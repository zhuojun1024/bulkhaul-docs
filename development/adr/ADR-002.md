# ADR-002  快照水合 + 集合读缓存（useCollection）

- 状态：已接受（2026-09-02 追认，Phase 4 落地）
- 关联：production-readiness-plan.md / lessons-learned.md

## 背景

薄客户端下 30+ 页面需要列表/交叉引用/派生读，逐实体 HTTP 请求量大且交叉引用列（ID→名称）需要批量数据。

## 决策

GET /api/snapshot 全量快照（34 集合 + logs）水合本地响应式 db；列表页经 useCollection（collectionStore 缓存 + 写后失效 + 分页/过滤复合 key）；交叉引用列读本地 db（find 下沉到各视图，仅声明本视图用到的键）。

## 备选方案

备选：① 每列表独立 /coll 请求（交叉引用需 N+1，否）；② 全局 Vuex/Pinia 大状态（与快照水合重复，否）。

## 后果

收益：读路径 O(1) 本地、写后域失效保证新鲜；成本：快照体积随数据增长（演示量级 <1MB 可接受），生产化需评估增量同步。
