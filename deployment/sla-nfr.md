# 非功能需求与 SLA 说明

> BulkHaul 交付文档 · V1.0（2026-09-02）· 演示定位（当前实测 + 生产化目标）

## 1  性能

| 指标 | 当前实测（演示量级） | 生产化目标 |
|---|---|---|
| 页面首屏加载 | < 1s（局域网，dist 静态 + 快照水合） | < 3s（含网络） |
| 全量快照 /api/snapshot | < 2s（种子态 ~200 调度单/365 磅单，< 1MB） | 数据增长后评估增量同步 |
| 列表页渲染 | 分页 10–20 条/页，< 500ms | 同 |
| 写操作响应（POST 后端） | < 500ms（局域网） | < 1s |
| E2E 全量回归 | 22 场景 110 断言 ~5 分钟 | 同（CI 基线） |
| 后端启动（含 Flyway 首启） | 40–60s | 同 |

**容量假设（演示）**：用户 ≤ 50 并发；调度单 ≤ 1000/月；磅单 ≤ 3000/月；快照 < 5MB。
超出后：/coll 分页已就绪（B2）；快照需改增量（ADR-002 成本项）；定时任务 leader 单实例已就绪（C4）。

## 2  可用性

| 项 | 当前 | 生产化目标 |
|---|---|---|
| 服务可用性 | 单实例（容器自愈 restart unless-stopped） | 99.5%（单实例 + 自愈）→ 99.9%（多副本） |
| 计划内停机 | 升级窗口 < 10 分钟（upgrade-migration.md） | 同 |
| 故障恢复 | RTO ≤ 1h / RPO ≤ 24h（backup-restore.md） | RTO ≤ 15min / RPO ≤ 5min（binlog + 多副本） |
| 健康检查 | /api/health（db + tables） | 同 + 外部拨测 |

## 3  安全（摘要，详见 deployment/security.md）

- 认证：bcrypt + JWT 480min + 验证码 + 失败锁定；
- 授权：RBAC 四层（后端单点校验权威）；
- 限流：Redis 固定窗口（登录按 IP/写按用户，429）；
- 审计：全量操作日志；
- 演示边界：无 TLS/无渗透测试/演示密钥（转生产必改）。

## 4  可维护性

- 前后端契约自动化（97 端点，test:contract）；
- E2E 幂等可复跑（110 断言，种子只读快照）；
- 结构化日志（traceId）+ actuator 指标；
- 文档体系：需求/验收/用户手册/API 参考/数据字典/Runbook/ADR（bulkhaul-docs）。

| 项 | 口径 |
